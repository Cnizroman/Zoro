# Зоро

Android-версия голосового ассистента Зоро.

## Возможности

- фоновая работа через Foreground Service;
- активация по слову «Зоро»;
- русское распознавание речи;
- озвучивание ответов;
- управление активным медиаплеером;
- пауза и продолжение;
- следующий и предыдущий трек;
- перемотка на 10 секунд;
- изменение громкости;
- определение текущего трека;
- запуск приложений;
- поиск Google.

## Сборка

Проект собирается через GitHub Actions:

Actions → Build APK → последний запуск → Artifacts → Zoro-debug-apk.
